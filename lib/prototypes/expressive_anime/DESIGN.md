# Expressive Anime Design

## Philosophy
"Fun, Bouncy, Expressive"

## Visuals
- **Colors**: Vibrant pastel/pop colors.
- **Shapes**: Rounded corners, card-based layout.
- **Motion**: Spring animations, playful interactions.

## Components
- **Card**: Soft shadows, rounded corners.
- **Typography**: Playful, readable fonts (e.g., Rounded Mplus 1c or similar if available, otherwise standard rounded sans).

## Implementation Plan

### Phase 1: Core Browsing (Current)
- [x] **Home Feed**: Horizontal scrolling list of trending anime.
- [ ] **Anime Details Page**:
    - Large Hero Image (sliver/parallax?).
    - "Add to List" floating action button.
    - Synopsis with "Read More".
    - Character horizontal list.
- [ ] **Navigation**: Bottom Navigation Bar or Custom Tab Bar.

### Phase 2: Discovery & Tracking
- [ ] **Search/Explore Page**:
    - Genre pills.
    - Search bar with micro-interactions.
- [ ] **My Library**:
    - Grid view of watched/planning anime.
    - Progress bars for episodes.

### Phase 3: Polish
- [ ] **Page Transitions**: Shared Element Transitions (Hero animations).
- [ ] **Micro-animations**: Button presses, like hearts, loading states.
